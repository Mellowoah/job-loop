# Yo Upgrade Preview

Private preview build of the upgraded Yo yo-yo game.

This is **not** the live site. The live game remains at https://yoyo.grok.me/.

Files served at the site root:
- `index.html` — standalone game
- `favicon.svg`
- `manifest.webmanifest`

To update the preview: replace `index.html` (and any sibling assets), commit, and push to `main`. If auto-deploy does not fire, trigger a manual deploy on the Render static site.
